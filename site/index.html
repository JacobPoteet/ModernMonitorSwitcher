Windows makes you rebuild it by hand, every time.

Turning one monitor off or putting the taskbar on the TV means a trip through Display settings. Then you do it all again to undo it.

  1. Open Settings, then System, then Display
  2. Pick the right numbered rectangle
  3. Choose “Disconnect this display”
  4. Repeat for the next screen
  5. Find the one that should be main
  6. Click “Keep changes” before it reverts
  7. Undo all of it tonight

Stays out of the way

Set it up once and forget it.

  • Starts with WindowsTurn it on once and it’s always in the tray.
  • Updates itselfNew versions install quietly, with no admin prompt.
  • Screens with real namesProfiles read “Left, Middle” instead of “DELL U2724D”. Identify puts each name on its screen.
  • Checks before it switchesWindows confirms every profile will work before anything changes on screen. If a layout ever goes wrong, one command puts Windows’ own layout back.

Setup

Three steps, once.

  1. Arrange your screens

    Set them up how you want in Windows Display settings, the way you always have.

  2. Save the layout

    Open the app, choose Save current layout and give it a name.

  3. Repeat, then switch

    Save one profile per setup. From then on, it’s one click. A short guide walks you through this the first time.

Questions

Windows warns me when I run the installer.

The installer isn’t code-signed, so SmartScreen shows a warning the first time. Choose More info, then Run anyway. Updates after that don’t trigger it.

Do I need admin rights?

No. It installs for your Windows account only, so neither the install nor its updates ask for permission.

What if a profile leaves me with no picture?

Run msw reset, or choose Restore the Windows layout in Settings. Both put back the arrangement Windows remembers for the monitors you have plugged in.

What does it cost?

Nothing. It’s open source under the Mozilla Public License 2.0.
