Welcome to Modern Monitor Switcher

A profile is a saved monitor arrangement: which displays are on, where they sit, their resolution, and which one is main. Save one for each way you use your desk, then switch between them in one click.

This takes about a minute. You will set up an arrangement in Windows, then save it here.

Arrange your displays

Open Windows display settings and set things up the way you want this profile to look.

  • Drag the monitors to match where they sit on your desk.
  • To leave a monitor out, select it and choose Disconnect this display under Multiple displays.
  • Tick Make this my main display on the one that should hold the taskbar.
  • Click Keep changes when Windows asks.

To switch to it later, use any of these:

  • Click the tray icon near the clock and pick the profile.
  • Press Switch next to it in this window.
  • Give it a hotkey with the button beside its name.

For another arrangement, change your displays in Windows again and choose Save current layout.
